# Constraint-Shift Math release protocol

The machine-readable source of truth is `../configs/protocol.json`.

机器可读的唯一真源是 `../configs/protocol.json`。

A score combines per-instance correctness with a strict whole-family pass.
The family, never an individual sibling, is the split and aggregation unit.
Witnesses and certificates are checked by deterministic validators.

评分同时衡量逐题正确率和整族严格通过；切分与聚合单位始终是题族。
证明和证书只由确定性的程序验证器判定。
